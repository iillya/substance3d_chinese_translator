# Substance 3D 中文翻译补全插件

为 Windows 版 **Adobe Substance 3D Painter（SP）** 和 **Adobe Substance 3D Designer（SD）** 补全界面、资源名称和部分节点文字的中文翻译。两个软件使用同一个安装包。

翻译只作用于显示：输入内容、资源原名和项目数据保留原样。关闭插件翻译后，恢复软件原来的显示，包括软件自带的中文。

[下载主分支安装包](https://github.com/iillya/substance3d_chinese_translator/raw/refs/heads/main/dist/substance3d_chinese_translator.zip) · [已发布版本](https://github.com/iillya/substance3d_chinese_translator/releases) · [反馈问题](https://github.com/iillya/substance3d_chinese_translator/issues) · [作者主页](https://space.bilibili.com/281243426)

## 可以做什么

- 补充菜单、按钮、参数标签、标签页、下拉选项和资源列表的中文显示。
- 在已适配的资源库面板中，用中文译名搜索资源，并保留原有分类范围。
- 查看文字原文，在资源悬停预览中补充中文名称。
- 按 `F10` 随时开关翻译；按 `Ctrl + 鼠标右键` 修改当前文字的译法。
- 加载多份词典，添加自己的常用术语和资源名称。
- 在 Painter 中单独开关图层面板翻译。
- 在 Designer 中选择启用节点标题和端口翻译，**此功能默认关闭**。
- 导出未翻译的资源名称，或从资源文件中提取词条，方便整理自己的词典。

插件依赖词典提供译文。没有对应词条的文字会保留原文。

## 支持的软件

系统要求：**Windows 10 / 11，64 位**。

| 软件 | 支持范围 | 说明 |
| --- | --- | --- |
| Substance 3D Painter | 7.2–10.0 | 安装包包含旧版所需组件 |
| Substance 3D Painter | 10.1 及以上 | 与 Designer 共用新版组件 |
| Substance 3D Designer | **14 及以上，包括 SD14** | 节点图翻译需单独开启 |

安装包会自动选择组件，无需额外安装 Python、Qt 或开发工具。macOS 和 Linux 暂不支持。

支持范围不代表每个小版本都经过完整实机测试。软件升级可能改变部分面板的显示方式；如果出现漏译或显示异常，请反馈具体软件版本和界面位置。

## 安装

下载 `substance3d_chinese_translator.zip`。GitHub 发布页中的 **Source code** 是源码压缩包，不用于直接安装。

安装或手动替换文件前，先完全退出对应软件。下面的“文档”指 Windows 当前用户的文档文件夹；如果它已迁移到 OneDrive 或其他磁盘，请使用实际位置。

### Painter

1. 打开以下目录；缺少的文件夹可以自行创建：

   ```text
   文档\Adobe\Adobe Substance 3D Painter\python\plugins
   ```

2. 在其中创建 `substance3d_chinese_translator` 文件夹，把 ZIP 的全部内容解压进去。
3. 确认这个文件存在：

   ```text
   ...\python\plugins\substance3d_chinese_translator\__init__.py
   ```

4. 启动 Painter，在 **Python** 菜单中启用“中文翻译补全插件”。首次加载时也可能显示目录名 `substance3d_chinese_translator`。
5. 主菜单栏出现 **中文翻译工具** 后，即可打开设置窗口。

Painter 的插件开关由 [Python 菜单](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/interface/main-menu/plugins-menu)管理。

### Designer

1. 打开以下目录；缺少的文件夹可以自行创建：

   ```text
   文档\Adobe\Adobe Substance 3D Designer\python\sduserplugins
   ```

2. 在其中创建 `substance3d_chinese_translator` 文件夹，把 ZIP 的全部内容解压进去。
3. 确认这个文件直接位于该文件夹中：

   ```text
   ...\python\sduserplugins\substance3d_chinese_translator\pluginInfo.json
   ```

4. 启动 Designer。如果没有出现 **中文翻译工具**，打开 **Tools（工具）→ Plugin Manager（插件管理器）**，检查并启用该插件。
5. 启动后稍等约 3 秒，插件会按上次保存的开关状态开始翻译。

Designer 的插件启用状态可在 [Plugin Manager](https://experienceleague.adobe.com/en/docs/substance-3d-designer/using/scripting/plugin-manager)中查看。

**目录检查：**安装文件夹中应直接包含 `__init__.py`、`pluginInfo.json`、`native` 和 `translations`。不要把整个压缩包多套一层目录，也不要只复制其中一个 DLL。

## 日常使用

两个软件都从主菜单栏的 **中文翻译工具** 打开设置。

| 操作 | 使用方法 |
| --- | --- |
| 开关翻译 | 按 `F10`，或切换“启用插件翻译” |
| 查看原文 | 悬停在支持原文提示的文字上；控件已有原生提示时优先保留原提示 |
| 修改译文 | 将鼠标放在目标文字上，按 `Ctrl + 鼠标右键`，填写译文并保存 |
| 中文搜索 | 在支持的资源库搜索框输入已有中文译名；多个关键词可用空格分隔 |
| 修改快捷键 | 点击工具窗口中的快捷键按钮，再按新组合；`Esc` 取消，`Backspace` 恢复默认 |

中文搜索作用于已适配的资源库或资源选择面板，并受当前分类和资源是否已加载影响。普通输入框、文件名输入框和软件的其他搜索入口仍按软件原有方式工作。

### 翻译选项

| 选项 | 默认状态 | 什么时候调整 |
| --- | --- | --- |
| 启用插件翻译 | 开启 | 需要临时查看软件原文时关闭 |
| 翻译图层面板 | 开启，仅 Painter | 希望图层名称保持原样显示时关闭 |
| 启用节点翻译 | 关闭，仅 Designer | 需要翻译节点标题、输入和输出端口时开启；大型节点图可能增加绘制开销 |
| 启用模糊匹配 | 开启 | 兼容大小写、全半角、下划线和空格等格式差异；遇到不合适的匹配时可关闭 |
| 启用全量扫描兜底 | 关闭 | 部分动态面板没有及时补翻译时，可临时开启；开启后约每 10 秒检查一次可见控件 |

图层名称只改变显示，不会重命名项目中的图层。节点图翻译也不会改写节点标识或连接关系。

精确词条优先于模糊匹配。例如，词典中有 `Rough Glass` 时，开启模糊匹配可识别 `roughglass`、`Rough_Glass` 等写法。词典中没有这个词时，扫描兜底不会自动生成译文。

## 修改翻译和添加词典

### 直接在界面改词

在文字上按 `Ctrl + 鼠标右键` 打开“更改翻译”。确认原文后填写新译文，点击“保存”即可刷新显示。

- 默认保存到 `translations/user_added_zh.json`，用于相同原文的通用翻译。
- 勾选“保存到专项词库”后，只对当前控件使用该译法，写入 `control_ids_zh.json`。
- 软件自带的中文通常保持原样；如果你明确为中文原文设置了自定义词条，也可以覆盖其显示。

更新会替换随包提供的 `control_ids_zh.json`。使用专项词库保存过自己的修改时，请在更新前复制留存，更新后再合并所需词条。

### 加载自己的词典

点击工具窗口中的“打开插件词条目录”，把词典放入 `translations` 文件夹。可以同时放入多份词典。

例如，创建一个 UTF-8 编码的 `zz_custom_zh.json`：

```json
{
  "$schema": "sp-translation-v1",
  "id": "custom-terms",
  "language": "zh-CN",
  "description": "我的常用术语",
  "translations": {
    "Concrete": "混凝土",
    "Rough Glass": "磨砂玻璃"
  }
}
```

- 文件名必须以 `_zh.json` 结尾。
- 左边写完整原文，右边写译文；空译文作为待翻译项，不会生效。
- 多份全局词典按文件名排序加载，后加载的同名词条覆盖前面的词条。`zz_custom_zh.json` 可用于覆盖随包词典，也会覆盖排在它前面的界面改词记录。
- 控件专项词条优先于全局词条。
- 手动编辑文件后，重启软件重新加载词典。只按 `F10` 不会重新读取文件。

建议把自己的词条放在独立文件中。随包提供的 `official_assets_zh.json`、`my_assets_zh.json` 和 `control_ids_zh.json` 会在在线更新时替换；其他独立用户词典会保留。

## 整理未翻译的资源

### 导出资源库名称

在“中文翻译工具”中点击 **导出资产库未翻译名称**，选择输出文件。

- Painter 会读取资产架中可访问的资源名称。
- Designer 会读取已注册的节点定义、已加载的资源包；必要时补充读取可见资源列表。

导出结果取决于软件当前可访问的资源，不等于扫描电脑上所有资源文件。已有译文的名称会被过滤。

### 从资源文件提取词条

1. 在“提取设置”中选择资源目录和输出 JSON 文件。
2. 在“提取选项”中选择需要的名称、标签、描述、分类等内容，也可选择文件名和文件夹名。
3. 点击“开始提取”，在窗口中查看进度；需要停止时点击“取消”。

提取器支持读取 SBS、SBSAR、SPSM、SPPR 等资源文件及部分压缩包中的可解析内容。已有输出文件中的译文会保留，新词条以空译文加入；失败详情会写入输出文件旁的 `_failures.txt`。

**提取只生成待翻译词条。**填好中文译文后，将文件放入 `translations` 并重启软件，才会用于显示翻译。

## 更新与卸载

### 在线更新

点击 **检查插件更新**，插件会检查 GitHub 上的最新正式发布版本。确认更新后会下载、校验并替换文件，完成后按提示重启软件。

更新不会自动关闭软件；当前会话继续使用已加载的版本。正在提取词条时，请先完成或取消任务。主分支中的改动尚未发布时，不会通过在线更新获得。

### 手动更新

先完全退出软件，复制留存自己的词典，再将新版安装包解压到原插件文件夹并覆盖文件。确认只保留一个启用的安装目录，最后启动软件。

### 卸载

完全退出软件后，删除对应目录中的 `substance3d_chinese_translator` 文件夹。需要保留个人词条时，先复制其中的 `translations` 文件夹。

## 常见问题

### 安装后没有“中文翻译工具”

检查安装路径和目录层级，再检查 Painter 的 Python 菜单或 Designer 的插件管理器是否已启用插件。文件更新后需要重新启动软件；Designer 启动时还会短暂延迟启用翻译。

### 一部分文字仍是英文

先确认总开关已开启，目标面板的独立开关也已开启。再检查词典是否有对应词条。对于新出现的面板，可以切换页面或临时开启扫描兜底。

资源名称、省略显示的标签和软件自定义界面可能走不同的显示路径。已有词条仍无法显示时，请提供软件完整版本、面板位置和截图，以便定位适配问题。

### 关闭翻译后，为什么还有中文？

关闭只撤销插件提供的显示翻译。软件官方中文、你自己输入的中文以及资源原本的中文名称都会保留。

### 修改词典后没有变化

确认文件位于插件安装目录的 `translations` 中，文件名以 `_zh.json` 结尾，格式有效且译文不为空。检查是否有排序更靠后的词典或控件专项词条覆盖它，然后重启软件。

### 中文搜索找不到资源

中文搜索需要资源已有对应译名，并且位于当前可访问的分类中。先用英文原名确认资源是否存在，再检查词条和当前分类。其他搜索框不一定支持插件的中文过滤。

### 启用后变慢或出现显示异常

先关闭全量扫描兜底；在 Designer 中可单独关闭节点翻译，尤其是大型节点图。用 `F10` 对比翻译开关前后的表现。反馈时注明具体操作、软件版本和相关截图。

### 更新失败或文件被占用

手动替换文件前完全退出 Painter / Designer，再确认没有残留的对应软件进程。网络更新不可用时，可从下载页取得安装包并手动更新；请先保留自己的词典。
