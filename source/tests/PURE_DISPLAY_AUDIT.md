# 纯显示层审核记录

日期：2026-09-25。分支：`pure-display-layer-experiment`。原生构建：`20260925-pure-display-audit-api15`。

本记录覆盖显示引擎、Python 启停与设置、词典查询、资源列表搜索与预览、Designer 节点绘制、构建及更新包边界。保留此前未提交的纯显示分支改动，没有回退到 Main，也没有提交或合并。本轮不代表所有 Adobe 版本和私有控件均完成实机验收。

## 已修复

| 问题 | 修复与验证 |
| --- | --- |
| IAT 恢复失败仍然 FreeLibrary，后续绘制可能访问已释放代码 | 原生卸载返回明确结果，Python 仅在成功后释放；失败保留 DLL。API 提升到 15，旧 DLL 明确拒绝加载。失败、异常、成功及重复释放有 Python 行为测试 |
| 卸载时插件窗口仍在原生调用栈中 | 原生翻译编辑窗口打开或绘制调用尚未返回时拒绝卸载；清除回调并关闭翻译。有原生测试 |
| 被修改导入表的模块先于引擎卸载 | 为已修改模块保留 Windows 模块引用，成功还原后释放。导入指针采用比较交换；其他插件接管的槽位保留并报告无法安全卸载。有第三方指针模拟测试 |
| 非 UI 线程绘制进入控件/词典路径，重入重复翻译 | 非 UI 线程与嵌套文字绘制只转发到 Qt；主线程统一处理翻译状态 |
| 原始下拉委托被宿主销毁后出现空白或空指针 | 使用 QPointer，并提供标准 Qt 委托回退；恢复时不安装空委托。显示代理禁止 setData/setItemData，交互继续使用原始模型索引 |
| 关闭翻译后资源格子仍保留中文行高和换行设置 | 关闭时恢复原委托及布局；重新开启时安装显示委托。有关闭后网格尺寸和 wordWrap 还原测试 |
| 中文搜索清理时误显示宿主原本隐藏的行 | 只记录、恢复插件自己隐藏的持久索引；保留真实模型、输入内容与选区。多词搜索先拆词再规范化，避免空格被提前消除 |
| 相同省略名称的不同节点串用缓存 | 缓存键包括端口方向和所属节点完整名；缓存上限 4096 项；词典变化立即失效。有两个同名省略标题分别翻译的绘制测试 |
| 中文原文的显式自定义译文被统一跳过 | 恢复 Main 的精确词典覆盖能力；显示委托标记本次已处理文本，避免二次翻译。有原生覆盖和重入保护测试 |
| SD 启动临时禁用翻译改写用户保存的开关 | 区分临时状态与持久设置；用户手动切换取消延迟启动；重复初始化不重复注册菜单 |
| 插件卸载后仍可能弹出延迟更新通知 | 通知改为有归属、可销毁的单次计时器；卸载取消并清理。有生命周期测试 |

保留 `QListWidget||QMenu||None||*` 的 `_skip_` 规则，遵守此前“回退去掉跳过规则”的要求。本轮未修改用户词典内容。

## 删除和收紧

- 删除仅写入、不读取的反向词典 `g_originals`，删除无引用的 `painterElidedLabelOwner`。
- 正式构建不生成快捷键/预览诊断字符串；节点诊断集合仅在诊断构建中存在。
- 已绑定资源搜索面板不再反复遍历子控件；销毁的委托记录在安装时清理。
- 预览文档仅在原生 HTML、资源或译文变化时重建，字体和尺寸未变时不重复设置。
- 全量扫描默认关闭；即便用户启用了兜底扫描，关闭翻译也会停止其 10 秒计时器。
- 修正“节点开关关闭就撤销全部挂钩”和“Designer/Qt 精确版本白名单”等过时说明。通用绘制入口与节点图共用，节点开关只控制节点路径。

没有删除仍被调用的公开导出、提取器、在线更新或功能开关。没有以粗略输入焦点过滤扩大跳过范围。

## 性能实测

测试环境为当前 Windows 电脑、Release 构建、Microsoft YaHei 12、离屏 Qt。加载实际 15,689 条全局词典和 35 条控件规则；每种环境运行 3 次取中位数。查询每项循环 200,000 次；相同未命中文本的 QLabel 绘制各 4,000 次，防止中英文长度不同造成错误比较。

| 测量项 | Qt 5.12.5 | Qt 6.5.3 | Designer Qt 6.5.8 |
| --- | ---: | ---: | ---: |
| JSON 解析及建立原生查询表 | 25.65 ms | 25.41 ms | 26.16 ms |
| 精确查询 | 0.051 μs | 0.048 μs | 0.049 μs |
| 规范化查询批次（部分词也可能精确命中） | 0.840 μs | 0.717 μs | 0.802 μs |
| 未命中查询 | 0.995 μs | 1.253 μs | 1.173 μs |
| 原生 QLabel 完整绘制，无引擎 | 27.26 μs | 15.38 μs | 15.46 μs |
| 引擎挂载、翻译关闭 | 27.95 μs | 15.60 μs | 15.71 μs |
| 引擎挂载、翻译开启 | 30.39 μs | 18.52 μs | 18.40 μs |
| 词典加载前后进程私有内存增量 | 5.98 MiB | 5.54 MiB | 5.46 MiB |

普通标签在该样本中增加约 3 μs/次完整绘制。关闭状态的小幅波动属于测量噪声，不能宣称零开销或负开销。词典内存增量不是整个插件常驻内存，加载时间不包含 Python 解析与 ctypes 传递。上述结果也不是 SP/SD 整个进程的 CPU 占用率。

默认没有全量扫描定时唤醒；显示事件过滤器与转发挂钩仍然存在。中文搜索发生于输入、模型或词典变化，并由单次计时器合并处理，不是持续后台扫描。

### 剩余热点：Designer 节点所属对象查找

`graphOwnerItem()` 仍遍历场景图元并比较变换。Designer Qt 6.5.8 的模拟场景中，一次查询在 100 / 1000 / 5000 个图元时分别约 **3.03 / 36.51 / 247.23 μs**。它发生在启用节点翻译的绘制路径，密集节点图可能累积为明显开销。

本轮未把它替换成未经宿主验证的几何猜测或跨帧裸指针缓存。后续应单独实现绘制批次内的索引，并验证移动、缩放、删除节点及端口继承变换后再启用。该问题已测量并保留记录，不能用普通标签的低开销掩盖。

## 交付及剩余边界

新版实验包为 `dist/substance3d_chinese_translator-pure-display.zip`，只包含既定 10 个发布文件。两个翻译 DLL 本轮重新编译；提取器源码未改，沿用现有二进制。完整提取器重编译仍缺 `sdks/deps`，需提供 `SP_DEPS_ROOT`；没有将其描述成全部二进制均重新构建。

本轮未部署或启动宿主。需继续实机检查 SD14 私有节点/资源面板、Painter 私有委托、复杂富文本、不同 DPI 和真实资源数据库。安全卸载检查降低风险，但一般 IAT 挂钩不能完全消除其他线程预先取走旧函数指针的竞态；运行中热卸载仍需谨慎验证，不能承诺任意第三方挂钩共存绝对安全。
